# 🚀 AI Code Reviewer

An AI-powered Code Review application built using **React.js**, **Node.js**, **Express.js**, and **Groq AI**.

This application allows developers to paste their code and receive professional production-level code reviews powered by Groq LLMs.

---

# ✨ Features

- 🤖 AI-powered code review
- ⚡ Groq AI integration
- 🧠 Production-level review suggestions
- 🔍 Detects:
  - Bugs
  - Performance issues
  - Security vulnerabilities
  - Bad coding practices
  - Readability issues
  - Scalability problems
- 💡 Provides:
  - Corrected code
  - Optimized code
  - Best practices
- 🎨 Clean and responsive UI
- 🌈 Syntax highlighting
- 📝 Markdown-supported AI responses

---

# 🛠️ Tech Stack

- Express.js
